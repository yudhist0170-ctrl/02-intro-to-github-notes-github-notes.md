## Penggunaan GitHub dalam Keseharian Saya

Saat ini saya menggunakan GitHub sebagai sarana belajar dan mengelola pekerjaan teknis. Saya membuat dan memperbarui README profil, menyimpan catatan serta tugas, dan mempelajari cara mengatur perubahan kode dengan Git.

Dalam proses belajar, saya menggunakan GitHub untuk memahami konsep repository, commit, branch, dan pull request. Dengan menyimpan pekerjaan di repository, saya dapat melihat riwayat perubahan, melanjutkan pekerjaan dari versi sebelumnya, dan membagikan proyek kepada orang lain.

Saya juga tertarik memakai GitHub untuk mendokumentasikan proyek programming, web development, dan geospasial yang saya kerjakan selama kuliah maupun internship. Saat ini penggunaan saya masih berfokus pada pembelajaran dan pengelolaan proyek; seiring bertambahnya pengalaman, saya ingin berkontribusi pada proyek kolaboratif dan open source.

Bagi saya, GitHub bukan hanya tempat mengunggah file. GitHub membantu saya membangun kebiasaan mendokumentasikan pekerjaan, membagi tugas menjadi perubahan kecil, dan belajar bekerja dengan alur kolaborasi yang digunakan dalam pengembangan perangkat lunak.
