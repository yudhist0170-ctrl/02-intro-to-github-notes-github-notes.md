# Sejarah Git dan GitHub

Sebelum Git, pengembang menggunakan berbagai sistem untuk melacak versi kode. Pada awal pengembangan Linux, perubahan sering dibagikan sebagai patch dan arsip. Pada 2002, proyek kernel Linux mulai menggunakan BitKeeper, sebuah distributed version control system (DVCS) berpemilik.

Pada 2005, hubungan antara komunitas pengembang Linux dan BitKeeper berubah, sehingga akses gratis BitKeeper dihentikan. Linus Torvalds dan para kontributor Linux kemudian membuat Git. Git dirancang agar cepat, terdistribusi, efisien untuk proyek besar, dan mendukung banyak branch yang berjalan secara paralel. Karena bersifat terdistribusi, setiap salinan repositori dapat menyimpan riwayat lengkap dan perubahan dapat dikerjakan secara lokal.

GitHub mulai tersedia secara resmi pada 10 April 2008. Platform ini memudahkan pengembang untuk meng-host repositori Git dan bekerja sama melalui fitur web seperti berbagi kode, diskusi, dan pull request. Git tetap menjadi sistem kontrol versi; GitHub menyediakan layanan dan alat kolaborasi di atas Git.

Pada Juni 2018, Microsoft mengumumkan rencana untuk mengakuisisi GitHub. Akuisisi tersebut selesai pada Oktober 2018. GitHub menyatakan akan tetap beroperasi sebagai platform yang terbuka bagi pengembang dan mendukung berbagai bahasa, alat, sistem operasi, dan layanan cloud.

## GitHub saat ini

Kini GitHub digunakan untuk meng-host proyek perangkat lunak dan mendukung banyak bagian dari alur kerja pengembangan. Repositori menyimpan kode dan dokumentasi; branch memisahkan pekerjaan; pull request membantu meninjau dan menggabungkan perubahan; issue membantu melacak pekerjaan; dan GitHub Actions dapat mengotomatiskan proses build, pengujian, serta deployment. GitHub juga menyediakan berbagai layanan untuk dokumentasi, kolaborasi, dan pengembangan proyek.

Menurut saya, perkembangan penting GitHub adalah perubahan dari tempat untuk menyimpan kode menjadi ruang kolaborasi yang membantu pengembang bekerja dari perencanaan sampai rilis. Git tetap menjadi fondasi kontrol versinya, sementara GitHub menyediakan antarmuka dan layanan kolaboratif.
